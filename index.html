MetaSports Analytics

Privacy Policy · Last updated October 24, 2026

MetaSports Analytics is a private, internal tool used only by the owner of the YouTube channels MetaSports and MetaSports FC to read the performance data of those channels. It is not offered to the public.

What data the app accesses

With the channel owner's permission, granted through Google sign-in, the app uses these read-only scopes:

  • youtube.readonly: channel and video details (titles, publish dates, public statistics).
  • yt-analytics.readonly: YouTube Analytics reports (views, watch time, retention, traffic sources).

The app cannot upload, edit, delete or comment on anything, and it does not access any other Google data.

How the data is used

The data is used only to produce performance reports for the channel owner, to help plan future videos. It is not sold, shared with third parties, or used for advertising.

Storage and retention

Reports are stored privately in the owner's own systems. Access tokens are kept as private secrets and are never published. The owner can delete stored reports at any time.

Revoking access

You can revoke the app's access at any time at myaccount.google.com/permissions.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
